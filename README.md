## Publish on GitHub Pages

Plan (Masaki, 2026-11-04): create the repository **private first**
for review; only switch it to public after Masaki confirms the
content. Note: on GitHub Free, Pages does not serve a site from a
private repository — the site goes live only after the switch to
public, which is exactly the intended order.

1. Create a GitHub repository named `<username>.github.io`
   (private first, no template). After switching to public, the
   site address is `https://<username>.github.io/`.
   - Alternative: any public repository, then enable
     Settings → Pages → Deploy from branch `main` / root.
2. Upload `index.html` (and this README) to the repository root.
3. Wait a minute, then open `https://<username>.github.io/`.
